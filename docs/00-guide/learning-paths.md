# 学习路径

完整题库用于查漏补缺，不建议从第一题顺序背到最后一题。先建立主干，再围绕目标岗位抽题训练。

时间有限时，可先完成[核心 100 题](core-100.md)。

## 基础路径

1. Agent 核心架构：整体架构、Runtime 与 Harness。
2. Transformer：Token、Attention、KV Cache。
3. 工具与 MCP：工具契约、执行闭环和安全边界。
4. 上下文与知识：Context、状态、记忆和压缩。
5. RAG：解析、召回、重排、生成与评测。

## 进阶路径

1. 任务规划、状态机、重规划与断点恢复。
2. 多模型路由、缓存和单位成功任务成本。
3. 多 Agent 选型、共享状态和冲突处理。
4. 安全、评测、Tracing、SLO 与事件响应。

## 架构岗路径

重点练习平台化、多租户、权限隔离、容量规划、容灾、成本核算和治理体系。每道题都应补充规模假设、组件边界、失败场景和量化指标。

## 专项路径

- RAG 岗：RAG 全章 → 上下文压缩 → 检索评测 → 权限治理。
- Coding Agent 岗：工程落地 → 工具与 Skills → 任务恢复 → 沙箱安全。
- 产品专题：先完成对应产品章节，再回到通用架构验证哪些是产品事实、哪些是工程建议。
