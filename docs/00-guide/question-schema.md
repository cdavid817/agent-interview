# 题目结构规范

题目使用稳定 ID，而不是依赖文件位置的连续显示编号。

```markdown
<a id="plan-023"></a>
### PLAN-023 · Agent 如何判断任务是否需要拆解？

> 稳定 ID：`PLAN-023`｜原题号：23

答案正文……

**相关知识点：** Task Decomposition、复杂度评分。
```

## 规则

- ID 由章节前缀和三位数字组成，一经发布不得复用或因移动文件而修改。
- 每个题目只保留一个主归属；跨章节关系使用链接和标签表达，不复制答案。
- 同义问法收录在主问题的“相似问法”，更深入的问题收录为“常见追问”。
- 单个题目文件最多 50 题，文件必须属于一个明确子主题。
- 产品、协议和价格等易变化内容应记录版本或核验日期。
- 修改后运行 `python scripts/validate.py`；涉及术语时再运行术语索引生成脚本。
