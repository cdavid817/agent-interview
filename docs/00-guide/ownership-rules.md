# 章节归属规则

跨领域题目只保留一个主归属，其他章节通过稳定 ID 引用。

| 章节 | 负责回答的核心问题 | 不负责展开的内容 |
|---|---|---|
| Agent 核心架构 | 系统全景、模块边界、Runtime/Harness | 某个能力的实现细节 |
| 任务规划与执行 | 任务如何识别、拆解、调度、停止和恢复 | 工具协议和权限实现 |
| 上下文与知识 | 本轮上下文、状态和记忆如何写入、召回与治理 | RAG 检索算法细节 |
| 工具、Skills 与 MCP | 能力如何描述、选择、授权、执行和复用 | 通用安全治理体系 |
| 多 Agent | 何时拆角色、如何通信协作和处理冲突 | 单 Agent 内部执行细节 |
| RAG | 知识如何解析、索引、召回、重排和引用 | 通用长期记忆 |
| 模型能力与成本 | 模型接入、路由、缓存、容量和成本 | 业务平台整体架构 |
| 安全治理与可观测性 | 跨组件策略、评测、审计、Tracing 和事件响应 | 单个工具的基础契约 |
| 工程落地与平台化 | Coding Agent、交付链路、平台和业务指标 | 模型或协议原理 |
| 产品专题 | 特定版本已经实现的产品能力 | 未经标注的通用设计推演 |

出现重叠时，优先判断题目要求候选人深入设计哪个组件。架构章保留概览，专业章节保留完整答案；相同标题进入[重复题候选报告](../reference/duplicate-questions.md)人工合并。
