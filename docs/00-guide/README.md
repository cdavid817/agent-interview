# 使用指南

题库采用“领域 → 章节 → 子主题 → 稳定题目 ID”四层导航。第一次使用建议先选择学习路径，再按统一回答框架练习。

- [学习路径](learning-paths.md)：按基础、进阶、架构岗和专项岗位组织复习顺序。
- [核心 100 题](core-100.md)：用于快速建立主干的稳定 ID 精选清单。
- [回答与评分框架](answer-rubric.md)：把答案组织为结论、机制、权衡、风险和指标。
- [题目结构规范](question-schema.md)：维护者新增、移动和引用题目的规则。
- [章节归属规则](ownership-rules.md)：处理跨领域问题，避免复制答案。
