## 官方一手资料

`opencode-CONTEXT.md` 是 OpenCode 仓库根目录 `CONTEXT.md` 的副本，由项目自己维护，MIT 协议。它定义了会话运行时的术语体系（系统上下文、上下文纪元、上下文源、中途系统消息等）、组件关系与客户端契约，并列出了项目自己标注的待澄清歧义。旁边那份《OpenCode 技术内幕》大量引用它。

引用这份资料的结论可视为项目官方表述，但仍需注意：它随仓库演进，副本有收录日期。

## 非官方分析资料

> **这两份不是官方文档。** 内容基于逆向分析、泄露源码或开源仓库阅读整理，与官方实际实现可能存在偏差。阅读时请把「机制设计思路」与「具体实现细节」分开看待：前者可迁移，后者随版本变化。

需要特别说明的是，这两份资料内部各自存在**自相矛盾之处**（例如 OpenCode 那份对内置上下文源的个数一处说三个、一处说四个，甚至同一句内不一致；Claude Code 那份对某项机制的适用范围有三处正文与一条代码注释对立）。题库在这些点上刻意采用开放式表述，不选边。
